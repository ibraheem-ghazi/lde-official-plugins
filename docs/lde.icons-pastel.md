# LDE Pastel

Soft pastel pages and folders with deep-toned labels and emblems.

Covers the same 59 file types, 43 named folders and Laravel files as LDE's built-in icon themes (Blade, Artisan, routes, migrations, models, policies, Livewire and more). After installing, pick **LDE Pastel** under Settings ▸ Appearance ▸ File icons.
