# LDE Orbit

A coloured disc per file type; folders wear a coloured dot with their emblem.

Covers the same 59 file types, 43 named folders and Laravel files as LDE's built-in icon themes (Blade, Artisan, routes, migrations, models, policies, Livewire and more). After installing, pick **LDE Orbit** under Settings ▸ Appearance ▸ File icons.
