# LDE Outline

Thin coloured outline icons: a page or folder outline with the file type inside.

Covers the same 59 file types, 43 named folders and Laravel files as LDE's built-in icon themes (Blade, Artisan, routes, migrations, models, policies, Livewire and more). After installing, pick **LDE Outline** under Settings ▸ Appearance ▸ File icons.
