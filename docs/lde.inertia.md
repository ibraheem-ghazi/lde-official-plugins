# Inertia

Inertia page names in `Inertia::render`, `inertia()` and `Route::inertia`:

- Completion, hover and Go to Definition for page names.
- A problem for a page that isn't there, with a quick fix that creates it, shaped like the
  project's other pages (pages folders from `config/inertia.php`, else `resources/js/Pages`).

LDE offers it to projects that require `inertiajs/inertia-laravel`.
