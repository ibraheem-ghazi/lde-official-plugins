# Livewire

Livewire support for LDE, following the Livewire version your project installs (3 or 4).

- Components in `<livewire:…>` and `@livewire('…')`: completion, hover and Go to Definition.
- Properties in `wire:model` and actions in `wire:click` (and other events), with problems for
  ones the component doesn't have and quick fixes that add them.
- `wire:` names and modifiers, `@livewire` keys.
- New Laravel File ▸ Livewire Component, as `make:livewire` makes it.

LDE offers it to projects that require `livewire/livewire`.
