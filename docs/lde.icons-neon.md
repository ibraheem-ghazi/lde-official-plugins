# LDE Neon

Dark tiles with glowing neon labels and outlined folders; made for dark themes.

Covers the same 59 file types, 43 named folders and Laravel files as LDE's built-in icon themes (Blade, Artisan, routes, migrations, models, policies, Livewire and more). After installing, pick **LDE Neon** under Settings ▸ Appearance ▸ File icons.
